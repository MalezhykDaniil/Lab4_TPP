
# Polynomial SDK

## 1. Призначення

Polynomial SDK — динамічна бібліотека для виконання
математичних операцій над многочленами з коефіцієнтами
типу double.

Бібліотека надає C ABI та призначена для використання
зовнішніми програмами, написаними на C і C++.

## 2. Склад пакунка

- include/Polinom.h — публічний заголовковий файл.
- lib/Polinom.lib — імпортна бібліотека для компонування.
- bin/Polinom.dll — динамічна бібліотека Windows.

## 3. Представлення многочлена

Коефіцієнти зберігаються в масиві за зростанням степенів x.

Наприклад:

    double p[] = {1.0, 2.0, 3.0};

Відповідає многочлену:

    P(x) = 1 + 2x + 3x^2

Параметр count визначає кількість коефіцієнтів.
Значення count має бути більшим за нуль.

## 4. Коди повернення

- POLINOM_OK (0) — операцію виконано успішно.
- POLINOM_INVALID_ARGUMENT (1) — некоректний аргумент,
  нульова кількість коефіцієнтів або недопустимий покажчик.
- POLINOM_BUFFER_TOO_SMALL (2) — вихідний буфер має
  недостатній розмір.

Для функцій, які приймають out_count, цей покажчик
має бути ненульовим. Функція записує в *out_count
потрібну кількість коефіцієнтів до перевірки місткості
вихідного буфера.

Якщо вихідний буфер замалий, функція повертає
POLINOM_BUFFER_TOO_SMALL і не записує в нього результат.

## 5. Опис функцій API

### 5.1. poly_add

    int poly_add(
        const double* a, size_t a_count,
        const double* b, size_t b_count,
        double* out, size_t out_capacity,
        size_t* out_count
    );

Призначення: додавання двох многочленів.

Вхідні параметри:
- a, a_count — коефіцієнти першого многочлена та їх кількість.
- b, b_count — коефіцієнти другого многочлена та їх кількість.
- out_capacity — місткість вихідного масиву.

Вихідні параметри:
- out — масив коефіцієнтів суми.
- out_count — кількість коефіцієнтів результату.

Потрібний розмір результату:
max(a_count, b_count).

### 5.2. poly_multiply

    int poly_multiply(
        const double* a, size_t a_count,
        const double* b, size_t b_count,
        double* out, size_t out_capacity,
        size_t* out_count
    );

Призначення: множення двох многочленів.

Потрібний розмір результату:
a_count + b_count - 1.

### 5.3. poly_evaluate

    int poly_evaluate(
        const double* p, size_t count,
        double x, double* result
    );

Призначення: обчислення значення P(x).

Параметри:
- p, count — коефіцієнти многочлена та їх кількість.
- x — точка, у якій обчислюється значення.
- result — покажчик на змінну для запису результату.

У разі успіху значення записується в *result.

### 5.4. poly_derivative

    int poly_derivative(
        const double* p, size_t count,
        double* out, size_t out_capacity,
        size_t* out_count
    );

Призначення: обчислення першої похідної многочлена.

Якщо count == 1, результат дорівнює {0.0}.
В інших випадках кількість коефіцієнтів результату
дорівнює count - 1.

### 5.5. poly_integral

    int poly_integral(
        const double* p, size_t count,
        double C, double* out, size_t out_capacity,
        size_t* out_count
    );

Призначення: обчислення первісної многочлена.

C — стала інтегрування, яка стає вільним членом
результуючого многочлена.

Кількість коефіцієнтів результату дорівнює count + 1.

## 6. Приклад використання

    const double a[] = {1.0, 2.0, 3.0};
    const double b[] = {4.0, 5.0};
    double out[10] = {};
    size_t out_count = 0;

    int status = poly_add(
        a, 3, b, 2, out, 10, &out_count
    );

За успішного виконання:
- status == POLINOM_OK;
- out містить {5.0, 7.0, 3.0};
- out_count == 3.

## 7. Граничні умови

1. Покажчики на вхідні масиви мають бути ненульовими.
2. Кількість вхідних коефіцієнтів має бути більшою за нуль.
3. Вихідні покажчики мають бути ненульовими.
4. Вихідний масив повинен уміщувати весь результат.
5. Якщо місткості недостатньо, результат не записується.
6. Значення NaN та нескінченності окремо не заборонені.
7. Переповнення типу double не перевіряється.
8. Перекриття вхідних і вихідних масивів не підтримується
   як гарантована поведінка; використовуйте окремий буфер.
9. Виділення пам'яті для вхідних і вихідних масивів
   виконує програма, що викликає бібліотеку.

## 8. Вимоги до підключення

Бібліотека призначена для Windows x64.

Для компонування програми потрібні:
- include/Polinom.h;
- lib/Polinom.lib.

Для запуску програми потрібен файл bin/Polinom.dll.

Polinom.dll має знаходитися поруч із виконуваним файлом
програми або в іншому каталозі, доступному механізму
пошуку DLL у Windows.

Архітектура бібліотеки та програми-клієнта має збігатися.
