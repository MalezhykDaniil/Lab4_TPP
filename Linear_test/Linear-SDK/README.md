# LinearSystemLib — SDK Package

## 1. Опис бібліотеки

`LinearSystemLib` — динамічна бібліотека C++ для розв’язання систем лінійних алгебраїчних рівнянь.

Бібліотека збирається у форматі DLL та надає програмний інтерфейс (API) для використання функцій іншими програмами.

Інтерфейс використовує `extern "C"` для сумісності на рівні C ABI.

## 2. Структура SDK

Пакунок розробника містить такі файли:

```text
SDK/
├── include/
│   └── LinearSystem.h
├── lib/
│   └── LinearSystemLib.lib
├── bin/
│   └── LinearSystemLib.dll
└── README.md
```

- `include/LinearSystem.h` — заголовочний файл з оголошеннями функцій.
- `lib/LinearSystemLib.lib` — бібліотека імпорту для компонування у Windows.
- `bin/LinearSystemLib.dll` — динамічна бібліотека.
- `README.md` — опис API та правил використання.

## 3. Підключення бібліотеки

Для використання бібліотеки необхідно:

1. Підключити `LinearSystem.h`.
2. Додати шлях до папки `include` у налаштування компілятора.
3. Підключити `LinearSystemLib.lib` під час компонування.
4. Забезпечити наявність `LinearSystemLib.dll` поруч із виконуваним файлом програми.

Приклад підключення:

```cpp
#include <iostream>
#include "LinearSystem.h"
```

## 4. Програмний інтерфейс API

Нижче наведено інтерфейс, передбачений для цієї версії бібліотеки. Оголошення мають відповідати фактичному файлу `LinearSystem.h`.

### 4.1. Функція `solve`

```cpp
int solve(
    const double* A,
    const double* b,
    double* x,
    int n
);
```

**Призначення:** розв’язання системи лінійних рівнянь \(Ax=b\).

**Параметри:**
- `A` — матриця коефіцієнтів розміром `n × n`, збережена послідовно за рядками.
- `b` — масив вільних членів довжини `n`.
- `x` — масив довжини `n`, у який записується знайдений розв’язок.
- `n` — кількість рівнянь і невідомих.

**Результат:** код стану виконання. Точне значення кодів успіху та помилки визначається реалізацією бібліотеки.

### 4.2. Функція `residual`

```cpp
double residual(
    const double* A,
    const double* b,
    const double* x,
    int n
);
```

**Призначення:** обчислення нев’язки отриманого розв’язку.

Нев’язка показує, наскільки обчислений вектор `x` задовольняє систему \(Ax=b\).

Параметри `A`, `b`, `x` та `n` мають ті самі значення, що й у функції `solve`.

Формула нев’язки залежить від реалізації бібліотеки.

### 4.3. Функція `checkSolution`

```cpp
int checkSolution(
    const double* A,
    const double* b,
    const double* x,
    int n,
    double tolerance
);
```

**Призначення:** перевірка точності отриманого розв’язку.

**Параметри:**
- `A` — матриця коефіцієнтів.
- `b` — вектор вільних членів.
- `x` — вектор розв’язку.
- `n` — розмір системи.
- `tolerance` — допустима похибка перевірки.

Функція повертає результат перевірки відповідно до реалізації бібліотеки.

### 4.4. Функція `gaussianElimination`

```cpp
int gaussianElimination(double* matrix, int n);
```

**Призначення:** виконання прямого ходу методу Гауса для розширеної матриці системи.

**Параметри:**
- `matrix` — розширена матриця розміром `n × (n + 1)`, збережена послідовно за рядками.
- `n` — кількість рівнянь.

Функція змінює матрицю під час виконання алгоритму. Формат повернення та правила обробки вироджених систем визначаються реалізацією.

## 5. Приклад використання

```cpp
#include <iostream>
#include "LinearSystem.h"

int main()
{
    const int n = 3;

    const double A[n * n] = {
         2,  1, -1,
        -3, -1,  2,
        -2,  1,  2
    };

    const double b[n] = { 8, -11, -3 };
    double x[n] = {};

    int status = solve(A, b, x, n);

    std::cout << "Solve status: " << status << '\n';

    int valid = checkSolution(A, b, x, n, 1e-9);

    if (valid == 1) {
        for (int i = 0; i < n; ++i) {
            std::cout << "x[" << i << "] = "
                      << x[i] << '\n';
        }

        std::cout << "Residual: "
                  << residual(A, b, x, n) << '\n';
    } else {
        std::cout << "Solution could not be verified.\n";
    }

    return 0;
}
```

## 6. Вхідні дані та граничні умови

- `n` має бути додатним числом.
- Масив `A` повинен містити `n × n` елементів.
- Масиви `b` та `x` повинні містити щонайменше `n` елементів.
- Усі передані вказівники мають бути дійсними та доступними для відповідних операцій.
- Матриця може бути виродженою або погано обумовленою. У таких випадках можливість знайти надійний розв’язок залежить від реалізації алгоритму.
- `tolerance` слід задавати невід’ємним числом.
- Для перевірки результату рекомендується використовувати невелику допустиму похибку, наприклад `1e-9`, з урахуванням масштабу вхідних даних.

Перед використанням бібліотеки потрібно перевірити точні коди повернення функцій у вихідному коді.

## 7. Збірка проєкту

Проєкт використовує CMake та стандарт C++20.

Основні команди для збирання:

```bash
cmake -S . -B build
cmake --build build --config Release
```

Після успішної збірки перевірте наявність DLL та бібліотеки імпорту у відповідних каталогах SDK.

## 8. Вимоги до запуску

Для запуску програми, яка використовує бібліотеку:

1. Виконуваний файл має бути зібраний для сумісної архітектури, наприклад x64.
2. `LinearSystemLib.dll` має бути доступна операційній системі під час запуску.
3. Версії заголовочного файлу та DLL повинні відповідати одна одній.
4. Якщо бібліотека не знаходиться, скопіюйте DLL у каталог із виконуваним файлом або налаштуйте шлях пошуку бібліотек.

## 9. Призначення пакунка

SDK призначений для передавання бібліотеки іншому розробнику, який може використовувати її API без необхідності включати вихідний код реалізації до свого проєкту.
