# Interpolation SDK

## 1. Загальна інформація

**Назва:** Interpolation SDK  
**Версія:** 1.0  
**Мова реалізації:** C++  
**Платформа:** Windows  
**Тип бібліотеки:** динамічна бібліотека (DLL)

Interpolation SDK призначений для виконання поліноміальної та лінійної інтерполяції, а також обчислення абсолютної похибки між фактичним і оціненим значеннями.

Бібліотека надає C-сумісний інтерфейс для використання з C++ та іншими мовами й інструментами, які підтримують виклик функцій через DLL.

## 2. Структура SDK

```text
InterpolationSDK/
├── README.md
├── include/
│   └── Interpolation.h
├── lib/
│   └── Interpolation.lib
└── bin/
    └── Interpolation.dll
```

Призначення файлів:

- `include/Interpolation.h` — оголошення функцій API та макрос експорту й імпорту.
- `lib/Interpolation.lib` — бібліотека імпорту для неявного зв'язування.
- `bin/Interpolation.dll` — динамічна бібліотека з реалізацією функцій.
- `README.md` — документація з використання SDK.

Файли `.lib` і `.dll` повинні відповідати одній збірці бібліотеки та мати сумісну архітектуру.

## 3. Підключення бібліотеки

### 3.1. Неявне зв'язування

Для неявного зв'язування необхідно:

1. Підключити каталог `include` до шляхів пошуку заголовкових файлів.
2. Додати `Interpolation.lib` до параметрів компонування проєкту.
3. Забезпечити доступність `Interpolation.dll` під час запуску програми, наприклад розмістити її поряд із виконуваним файлом.

Приклад підключення:

```cpp
#include "Interpolation.h"
```

Після налаштування проєкту функції можна викликати безпосередньо за їхніми іменами.

### 3.2. Явне зв'язування

Для явного зв'язування використовується Windows API:

- `LoadLibrary()` — завантажує `Interpolation.dll`.
- `GetProcAddress()` — отримує адресу експортованої функції.
- `FreeLibrary()` — звільняє завантажену бібліотеку після завершення роботи з нею.

За такого способу завантаження програма отримує адреси функцій під час виконання. Для самого завантаження та отримання адрес функцій не потрібні заголовок бібліотеки й файл імпорту `.lib`, проте програмі необхідно знати точні сигнатури функцій і правильно оголосити відповідні вказівники на функції.

Якщо DLL не вдалося завантажити або потрібну функцію не знайдено, програма повинна обробити цю помилку.

## 4. Загальні правила використання API

Усі функції бібліотеки повертають значення типу `double`.

Для позначення помилкового результату використовується `NaN` — спеціальне значення типу `double`, яке можна перевірити за допомогою `std::isnan()`.

Вхідні числові аргументи мають бути скінченними, якщо інше прямо не зазначено в описі конкретної функції.

Для функцій, які приймають масиви, викликаюча програма відповідає за правильність вказівників і за те, щоб кожен масив містив щонайменше `count` елементів. Бібліотека не може визначити фактичний розмір масиву лише за вказівником.

## 5. Опис API

### 5.1. Функція `lagrange`

**Сигнатура:**

```cpp
double lagrange(
    const double* x,
    const double* y,
    int count,
    double target
);
```

**Призначення:** обчислення значення інтерполяційного полінома Лагранжа в заданій точці.

**Параметри:**

| Параметр | Тип | Опис |
|---|---|---|
| `x` | `const double*` | Масив координат вузлів інтерполяції |
| `y` | `const double*` | Масив значень функції у відповідних вузлах |
| `count` | `int` | Кількість вузлів |
| `target` | `double` | Точка, у якій обчислюється значення |

**Результат:** обчислене значення полінома Лагранжа.

**Умови коректного використання:**

- `x` і `y` не повинні бути `nullptr`.
- `count` повинен бути більшим за нуль.
- Усі координати та значення функції повинні бути скінченними.
- Координати вузлів `x` повинні бути попарно різними.
- `target` повинен бути скінченним.

Якщо перевірка вказівників, кількості вузлів, скінченності даних або унікальності координат не проходить, функція повертає `NaN`.

Екстраполяція математично можлива для полінома Лагранжа, тому функція не обмежує `target` інтервалом вузлів.

Якщо проміжні обчислення дають нескінченне значення або `NaN`, функція повертає `NaN`.

### 5.2. Функція `linearInterpolation`

**Сигнатура:**

```cpp
double linearInterpolation(
    double x0,
    double y0,
    double x1,
    double y1,
    double target
);
```

**Призначення:** обчислення значення лінійної інтерполяції між двома точками.

**Параметри:**

| Параметр | Тип | Опис |
|---|---|---|
| `x0` | `double` | Координата першої точки |
| `y0` | `double` | Значення функції в першій точці |
| `x1` | `double` | Координата другої точки |
| `y1` | `double` | Значення функції в другій точці |
| `target` | `double` | Координата, у якій обчислюється результат |

**Результат:** оцінене значення функції на відрізку між двома заданими точками.

Функція підтримує як інтерполяцію, так і екстраполяцію. Цільова координата `target` може знаходитися як між `x0` та `x1`, так і за межами цього відрізка.

Якщо будь-який аргумент не є скінченним або `x0 == x1`, функція повертає `NaN`.

Екстраполяція виконується за тією самою формулою лінійної інтерполяції, продовжуючи пряму за межі заданих точок.

### 5.3. Функція `interpolate`

**Сигнатура:**

```cpp
double interpolate(
    const double* x,
    const double* y,
    int count,
    double target
);
```

**Призначення:** кусково-лінійна інтерполяція за набором вузлів.

**Параметри:**

| Параметр | Тип | Опис |
|---|---|---|
| `x` | `const double*` | Масив координат вузлів |
| `y` | `const double*` | Масив значень функції у вузлах |
| `count` | `int` | Кількість вузлів |
| `target` | `double` | Точка, у якій обчислюється результат |

**Результат:** оцінене значення функції за кусково-лінійною інтерполяцією.

**Умови коректного використання:**

- `x` і `y` не повинні бути `nullptr`.
- `count` повинен бути не меншим за два.
- Усі значення `x`, `y` та `target` повинні бути скінченними.
- Координати `x` повинні строго зростати.
- Цільова точка повинна належати інтервалу від `x[0]` до `x[count - 1]`.

Якщо `target` точно збігається з координатою одного з вузлів, повертається відповідне значення `y`.

Якщо `target` лежить між двома сусідніми вузлами, функція виконує лінійну інтерполяцію між ними.

Якщо будь-яка перевірка не проходить або цільова точка виходить за межі заданого інтервалу, функція повертає `NaN`.

### 5.4. Функція `interpolationError`

**Сигнатура:**

```cpp
double interpolationError(
    double actual,
    double estimated
);
```

**Призначення:** обчислення абсолютної похибки між фактичним і оціненим значеннями.

**Параметри:**

| Параметр | Тип | Опис |
|---|---|---|
| `actual` | `double` | Фактичне значення |
| `estimated` | `double` | Оцінене значення |

**Результат:** абсолютна похибка, що обчислюється за формулою:

\[
E = |actual - estimated|
\]

Якщо хоча б один аргумент не є скінченним або різниця призводить до нескінченного результату, функція повертає `NaN`.

## 6. Обробка помилок і граничних випадків

Бібліотека використовує `NaN` для позначення помилкового результату в ситуаціях, визначених реалізацією функцій.

| Граничний випадок | Поведінка |
|---|---|
| Нульовий вказівник `x` або `y` у функціях, що приймають масиви | `NaN` |
| `count <= 0` у `lagrange` | `NaN` |
| `count < 2` у `interpolate` | `NaN` |
| Повторювані координати вузлів у `lagrange` | `NaN` |
| Однакові координати `x0` та `x1` у `linearInterpolation` | `NaN` |
| Невпорядковані або повторювані координати в `interpolate` | `NaN` |
| `NaN` або нескінченність у вхідних даних | `NaN` |
| Цільова точка за межами інтервалу в `interpolate` | `NaN` |
| Цільова точка за межами відрізка в `linearInterpolation` | `NaN` |
| Некоректний результат проміжних обчислень | `NaN` |

Після виклику функції, для якої можливий помилковий результат, рекомендується перевіряти його за допомогою `std::isnan()` або `std::isfinite()`.

Повернення `NaN` не розрізняє причини помилки. API не передбачає окремого коду помилки чи текстового повідомлення.

## 7. Керування пам'яттю

Бібліотека не виділяє і не звільняє пам'ять для масивів `x` і `y`. Викликаюча програма відповідає за їхнє створення, достатній розмір і час життя.

Функції повертають числові результати за значенням. Окреме звільнення пам'яті для результатів не потрібне.

## 8. Сумісність і зв'язування

Заголовковий файл `Interpolation.h` використовує `extern "C"` для C++-компілятора, що забезпечує C-сумісне іменування експортованих функцій.

Макрос `INTERPOLATION_API` керує експортом та імпортом функцій:

- `INTERPOLATION_EXPORTS` має бути визначений під час збирання DLL.
- У клієнтській програмі цей макрос зазвичай не визначається, тому декларації використовують `__declspec(dllimport)`.

DLL, файл імпорту та клієнтська програма повинні мати сумісну архітектуру, наприклад x64.

Для явного зв'язування назви функцій, які передаються до `GetProcAddress()`, мають відповідати фактичним експортованим іменам DLL.

## 9. Обмеження

SDK не перевіряє фактичний розмір пам'яті, на яку вказують `x` та `y`. Передавання вказівника на масив, що містить менше ніж `count` елементів, може призвести до невизначеної поведінки.

Функції не призначені для автоматичного сортування вузлів, виправлення некоректних даних або розрізнення різних причин помилок.

`lagrange` використовує поліноміальну інтерполяцію, а `interpolate` — кусково-лінійну. Ці методи можуть давати різні результати для однакових вхідних даних.
